# Community Benchmarks

Real, contributed measurements of MAJI Skills — generated by [`analytics/aggregate.py`](./analytics/aggregate.py) from the `summary.json` files in [`community-benchmarks/`](./community-benchmarks).

Every run is its own row. We do **not** average away disagreement: a run where the skills made replies *longer* stays visible. The point is honest data, not a flattering headline. How to contribute: [CONTRIBUTING-BENCHMARKS.md](./CONTRIBUTING-BENCHMARKS.md).
